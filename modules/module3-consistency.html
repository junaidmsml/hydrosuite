Double Mass Curve Analysis for Long-Term Data

Compare a station against a regional reference series, detect a change in slope (regime shift), adjust the older record and verify the correction.

What This Module Does

Double Mass Curve

Plots cumulative station rainfall against cumulative reference rainfall, the standard consistency test.

Break Detection

Finds the point where two straight-line fits (least squares) match the curve best.

Data Adjustment

Scales the older record by m₂/m₁ so it matches the recent regime.

Before / After

Original and corrected curves with slopes, so you can verify the fix.
