Unit Hydrograph & Direct Runoff

Analyze storm hydrographs to separate base flow from direct runoff, derive unit hydrographs, and compute catchment characteristics. Includes S-curve generation for different durations.

What This Module Does

Base Flow Separation

Separate base flow from direct runoff using the straight-line method.

Direct Runoff Hydrograph

Extract DRH by subtracting base flow from the total hydrograph.

Unit Hydrograph

Derive the D-hour unit hydrograph (DRH ÷ effective rainfall depth), check it integrates to 1 mm, and build the S-curve.

Rich Visualization

Multiple charts showing base flow, DRH, UH, and runoff distribution.
